# الأمانة العامة لمحافظة الرقة - تطبيق التعميمات

تطبيق ويب متقدّم (PWA) لعرض التعاميم والأوامر الإدارية والقرارات الرسمية للعاملين في المحافظة، مع قراءة الكتاب وتنزيله وإرفاق الصور.

## هيكل المشروع

```
site/                 ملفات التطبيق (هي التي تُنشر)
  index.html          الواجهة
  manifest.json       بيانات التثبيت كتطبيق
  sw.js               العمل دون إنترنت
  icons/              أيقونات علم سوريا
.github/workflows/pages.yml   النشر التلقائي على GitHub Pages
```

## النشر على GitHub Pages

1. أنشئ مستودعاً جديداً على GitHub (مثال: `raqqa-circulars`) وارفع إليه كل محتويات هذا المجلد.
2. من المستودع: **Settings ← Pages ← Build and deployment ← Source: GitHub Actions**.
3. عند كل رفع إلى الفرع `main` يُنشر التطبيق تلقائياً، ويظهر الرابط في تبويب **Actions**:
   `https://USERNAME.github.io/raqqa-circulars/`
4. افتح الرابط ثم ثبّته كتطبيق:
   - أندرويد/كمبيوتر (Chrome أو Edge): «تثبيت التطبيق».
   - آيفون (Safari): مشاركة ← «إضافة إلى الشاشة الرئيسية».

## التحديث

عدّل الملفات داخل `site/`، وغيّر رقم الإصدار في `site/sw.js` (`raqqa-v1` ← `raqqa-v2`) ليصل التحديث للمستخدمين.

## ملاحظة

الإصدار الحالي نموذج للواجهة: الكتب المنشورة تُحفظ في متصفح كل مستخدم فقط. لإيصالها إلى جميع العاملين يلزم نظام خلفي (خادم وقاعدة بيانات وحسابات وصلاحيات وإشعارات).
